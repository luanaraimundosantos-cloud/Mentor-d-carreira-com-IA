# Projeto: Programação com IA - Construindo um Mentor de Carreiras

Projeto desenvolvido com base nos conceitos de desenvolvimento de aplicações com Inteligência Artificial, segurança de código, System Prompts, GuardRails e gestão de tokens.

## Funcionalidades
1. **System Prompt Especializado:** Define o comportamento da IA exclusivamente como um mentor profissional.
2. **GuardRails de Segurança:** Bloqueia conteúdos fora do escopo de carreiras e mercado de trabalho.
3. **Gestão de Tokens:** Monitoriza e limita o consumo de recursos por sessão.
4. **Interface Interativa:** Permite simular conversas dinâmicas em linha de comando.

## Como Executar
Certifique-se de ter o Python instalado. No terminal, execute:

```bash
python main.py
